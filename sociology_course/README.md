# Sociology: SOC (Nijole V. Benokraitis)

## 📌 Course Overview
This directory contains computational scripts, data analysis models, and conceptual implementations for introductory sociology coursework using **Nijole V. Benokraitis's *SOC*** framework. The projects apply Python automation, data processing (`pandas`), and visual analytics (`matplotlib`, `seaborn`) to core sociological concepts.

## 🛠 Tech Stack & Dependencies
* **Language:** Python 3.x
* **Libraries:** `pandas`, `matplotlib`, `seaborn`, `numpy`
