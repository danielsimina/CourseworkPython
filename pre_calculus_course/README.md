# Precalculus Coursework (Robert F. Blitzer - 7th Edition)

## 📌 Course Overview
This repository module contains interactive Python scripts, mathematical visualizers, and algorithmic solvers covering core precalculus and college algebra concepts from **Robert F. Blitzer's *Precalculus* (7th Edition)**.

## 🗂 Chapter Breakdowns & Python Tools

* **Chapter 1: Functions & Graphs (`ch1_functions_graphs.py`)**
  * Graphing functional behavior, evaluating domain/range, and visualizing function transformations.
* **Chapter 2: Polynomial & Rational Functions (`ch2_polynomial_rational.py`)**
  * Analyzing polynomial zero multiplicities, end behavior, and horizontal/vertical asymptotes.
* **Chapter 3: Exponential & Logarithmic Functions (`ch3_exponential_logarithmic.py`)**
  * Modeling exponential growth/decay and logarithmic scale transformations.
* **Trigonometric Functions (`trigonometry.py`)**
  * Interactive unit circle calculations and multi-panel wave plots for $\sin(x)$, $\cos(x)$, $\tan(x)$, and $\cot(x)$ with asymptote masking.

## 🛠 Tech Stack & Dependencies

* **Libraries:** `math`, `numpy`, `matplotlib`
